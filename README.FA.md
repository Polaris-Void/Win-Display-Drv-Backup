## معرفی

گاهی آپدیت درایور کارت گرافیک مشکل‌ساز می‌شود: صفحه سیاه، افت کارایی، خراب شدن کنترل‌پنل، یا نصب تازه ویندوز که درایور گرافیک درستی ندارد. پروژه **Display Driver Backup & Restore** یک شبکه ایمنی ساده برای همین موقعیت‌هاست.

- فایل `Backup_Display_Driver.bat` درایورهای شخص ثالث از کلاس **Display** (مثل NVIDIA، AMD و Intel) را که اکنون نصب هستند در یک پوشه محلی ذخیره می‌کند.
- فایل `Restore_Display_Driver.bat` همان درایورهای ذخیره‌شده را هر زمان لازم باشد دوباره نصب می‌کند.

نیازی به نصب برنامه یا ابزار اضافه نیست. همه چیز با ابزارهای داخلی خود ویندوز کار می‌کند.

## ویژگی‌ها

- اجرای تک‌کلیکی: فقط روی اسکریپت دوبار کلیک کنید
- درخواست خودکار دسترسی Administrator (پنجره UAC)، بدون نیاز به «Run as administrator» دستی
- فقط درایورهای شخص ثالث کلاس Display (`oem*.inf`) پشتیبان‌گیری می‌شوند، نه کل درایور استور
- بازیابی، همه پکیج‌های درایور داخل پوشه پشتیبان (از جمله زیرپوشه‌ها) را نصب می‌کند
- پیام‌های وضعیت واضح (`[INFO]`، `[WARN]`، `[ERROR]`، `[SUCCESS]`) و کد خروج استاندارد
- بدون نیاز به اینترنت
- اسکریپت‌ها متن ساده‌اند و در چند دقیقه قابل خواندن و بررسی هستند

## پیش‌نیازها

| مورد | جزئیات |
|---|---|
| سیستم‌عامل | ویندوز ۱۰ یا ویندوز ۱۱ |
| سطح دسترسی | Administrator (به‌صورت خودکار درخواست می‌شود) |
| ابزارها | `pnputil` و Windows PowerShell 5.1 (هر دو همراه ویندوز هستند) |

## شروع سریع

### ۱. پشتیبان‌گیری از درایور فعلی

1. این مخزن را دانلود یا کلون کنید.
2. روی **`Backup_Display_Driver.bat`** دوبار کلیک کنید.
3. پنجره UAC را تأیید کنید.
4. منتظر پیام `[SUCCESS] Display drivers backed up successfully.` بمانید.

### ۲. بازیابی در زمان نیاز

1. روی **`Restore_Display_Driver.bat`** دوبار کلیک کنید.
2. پنجره UAC را تأیید کنید.
3. منتظر پیام `[SUCCESS] Display drivers restored successfully.` بمانید.
4. **کامپیوتر را ری‌استارت کنید** تا تغییرات اعمال شود.

## محل پشتیبان

هر دو اسکریپت از یک پوشه ثابت روی درایو سیستم استفاده می‌کنند:

</div>

```
%SystemDrive%\Backup_Display_Driver
```

<div dir="rtl">

در بیشتر سیستم‌ها این مسیر `C:\Backup_Display_Driver` است.

> **قصد نصب مجدد ویندوز دارید؟** پیش از فرمت، این پوشه را روی فلش یا دیسک دیگری کپی کنید. بعد از نصب ویندوز جدید، آن را به همان مسیر برگردانید و اسکریپت بازیابی را اجرا کنید.

برای استفاده از مسیر دیگر، این خط را در ابتدای **هر دو** اسکریپت ویرایش کنید:

</div>

```bat
set "BACKUP_DIR=%SystemDrive%\Backup_Display_Driver"
```

## نحوه کار

**پشتیبان‌گیری**

1. دسترسی Administrator را بررسی می‌کند و در صورت نیاز خودش را با سطح دسترسی بالا دوباره اجرا می‌کند.
2. اگر پوشه پشتیبان وجود نداشته باشد آن را می‌سازد.
3. با دستور `Get-WindowsDriver -Online` در PowerShell، درایورهای شخص ثالث نصب‌شده با کلاس *Display* (شناسه `{4d36e968-e325-11ce-bfc1-08002be10318}`) را فهرست می‌کند.
4. هر کدام را با `pnputil /export-driver` خروجی می‌گیرد.

**بازیابی**

1. دسترسی Administrator را بررسی می‌کند و در صورت نیاز خودش را با سطح دسترسی بالا دوباره اجرا می‌کند.
2. وجود پوشه پشتیبان و فایل‌های `.inf` داخل آن را بررسی می‌کند.
3. همه را با دستور زیر نصب می‌کند:

</div>

```bat
pnputil /add-driver "%BACKUP_DIR%\*.inf" /subdirs /install
```

## کدهای خروج

بخش PowerShell در اسکریپت پشتیبان‌گیری این کدها را برمی‌گرداند:

| کد | معنی |
|---|---|
| `0` | همه درایورهای Display با موفقیت پشتیبان‌گیری شدند |
| `1` | خواندن فهرست درایورها ناموفق بود یا حداقل یک خروجی‌گیری خطا داد |
| `2` | هیچ درایور شخص ثالث از کلاس Display پیدا نشد |

## نکات مهم

- فقط درایورهای **شخص ثالث** پشتیبان‌گیری می‌شوند. درایور پیش‌فرض ویندوز (*Microsoft Basic Display Adapter*) جزو خود ویندوز است و خروجی گرفته نمی‌شود.
- اسکریپت بازیابی **همه** پکیج‌های درایور داخل پوشه پشتیبان را نصب می‌کند. فقط درایورهایی را که واقعاً می‌خواهید بازیابی شوند در آن نگه دارید.
- اگر پوشه پشتیبان وجود نداشته باشد یا فایل `.inf` نداشته باشد، اسکریپت بازیابی با یک پیام واضح متوقف می‌شود و هیچ تغییری نمی‌دهد.
- بعد از بازیابی، ری‌استارت توصیه می‌شود.

## عیب‌یابی

| مشکل | راه‌حل |
|---|---|
| `Get-WindowsDriver failed` | مطمئن شوید اسکریپت با دسترسی Administrator اجرا شده و ویندوز سالم است (`sfc /scannow` و `DISM /Online /Cleanup-Image /RestoreHealth`). |
| `No third-party Display class drivers found` | احتمالاً سیستم شما از درایور عمومی مایکروسافت استفاده می‌کند. ابتدا درایور سازنده کارت گرافیک را نصب کنید و دوباره پشتیبان بگیرید. |
| `Display backup directory not found` | ابتدا پشتیبان‌گیری کنید، یا پوشه ذخیره‌شده را به مسیر مورد انتظار برگردانید. |
| پنجره خیلی سریع بسته می‌شود | اسکریپت‌ها ۵ ثانیه قبل از بستن صبر می‌کنند. برای دیدن کامل خروجی، آن‌ها را از داخل Command Prompt باز اجرا کنید. |

## سلب مسئولیت

این اسکریپت‌ها روی سیستم شما درایور نصب می‌کنند. استفاده از آن‌ها بر عهده خود شماست و فقط درایورهایی را بازیابی کنید که به آن‌ها اعتماد دارید و با سخت‌افزارتان سازگارند. توسعه‌دهنده مسئولیتی در قبال آسیب یا از دست رفتن داده ندارد.
